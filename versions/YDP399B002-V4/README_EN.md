## Overview

OSPTEK **3.99″ 400×960 TFT** is a **SPI / RGB** color display module driven by **ST7701SN-G5-1**. Suited to bar-style HMI and narrow side panels.

Spec ID (repository name): `tft-3.99-400x960-spi_rgb-st7701`

Current module version: **YDP399B002-V4**. Electrical and mechanical details follow [`docs/YDP399B002-V4.pdf`](./docs/YDP399B002-V4.pdf).

## Specifications

| Item | Spec |

| Type | TFT (color) |
| Resolution | 400×960 |
| Interface | 3-line SPI / 18-bit RGB |
